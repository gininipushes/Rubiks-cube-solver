How it works

Phase 1 uses IDA* to reach the subgroup ⟨U, D, R2, L2, F2, B2⟩, where every piece is oriented and the middle-layer edges sit in the middle layer. Phase 2 solves the rest using only those moves. Coordinates, move tables and BFS pruning tables make each search step a handful of array lookups. The solver keeps trying longer phase-1 paths until the total length hits the target.
